# Frühere Entwürfe

Diese Dateien bleiben zur Orientierung erhalten, gehören aber nicht zum aktiven Build.

- `previous-ui/`: frühere Stationen, Technikproben und Download-Tutor. Ihre Einstiegspunkte werden vom aktuellen Lernpfad nicht aufgerufen. Gemeinsame, weiterhin verwendete Komponenten bleiben unter `apps/web/`.
- `reviews/`: frühere Prüfnachweise, ausdrücklich vom aktuellen Prüfstand getrennt.
- `notes/`: frühere persönliche Arbeitsnotizen; sie gehören nicht zum veröffentlichten Lernauftrag.
- `github-actions/`: stillgelegte CI-/Release-Workflows. Das Projekt wird lokal geprüft und statisch für Vercel gebaut. Hier abgelegte YAML-Dateien führt GitHub nicht aus.

Das Archiv ist keine zweite unterstützte Anwendung. Aktuelle Start- und Prüfschritte stehen in [START.md](../docs/START.md).
